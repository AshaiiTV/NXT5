# League of Legends statistics icons

`minions.png` is the unmodified minion (CS) icon sprite from the League of Legends client, patch 12.23.

Source: https://raw.communitydragon.org/12.23/plugins/rcp-fe-lol-match-history/global/default/icon_minions.png

League of Legends assets belong to Riot Games. `MinionIcon` uses the first 52 × 56 state as an alpha mask so the pictogram inherits the interface color. The file is served locally, without a third-party image request.
