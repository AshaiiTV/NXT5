# Kit de publication YouTube : tutoriel « Importer une partie dans NXT5 »

Fichiers produits par `tools/promo-video/v3` :

- `out/nxt5-tuto-importer.mp4` : la vidéo (2 min 31 s, 1080p30, H.264 + AAC, −16 LUFS) ;
- `out/nxt5-tuto-importer-sans-musique.mp4` : la même vidéo avec les seuls bruitages ;
