# Permissions et dépannage

## Permissions

Les droits dépendent du rôle enregistré dans l'équipe sélectionnée. Les paramètres personnels sont dans [Paramètres](/parametres) ; les accès du roster sont dans [Gestion équipe](/gestion-equipe). Une action bloquée doit être vérifiée avec le capitaine ou un membre du staff autorisé.

Les abonnements ne sont pas encore lancés : tous les outils restent accessibles quel que soit le statut affiché dans **Mon abonnement**. Cela ne supprime pas les permissions de l’équipe. Une attribution administrative ne déclenche ni paiement ni reconduction automatique ; les tarifs restent une prévisualisation réservée à l’administration.

## Compte et connexions

Les méthodes de connexion proposées dépendent des services activés. Pour ajouter une méthode à un compte existant, se connecter à ce compte puis ouvrir **Paramètres → Connexions associées**. Une adresse déjà utilisée ne provoque aucune fusion automatique.

Pour modifier l’e-mail ou dissocier un service, un mot de passe NXT5 est nécessaire. Si le compte n’en possède pas, **Sécurité** permet de demander un lien par e-mail pour en créer un. Après ce parcours, il faut se reconnecter et associer à nouveau ses connexions externes. Les notifications e-mail demandent une adresse vérifiée ; leur choix se règle dans Paramètres.

## Commande Discord refusée

Vérifier la liaison personnelle au bot, l’équipe active dans Discord et l’appartenance à cette équipe NXT5. Si des rôles Discord sont configurés dans [Bot Discord](/bot-discord), il faut aussi en posséder au moins un : un rôle Discord ne remplace jamais les droits NXT5. Les connexions au site avec Discord, au bot et au serveur d’équipe sont distinctes. Voir [le parcours Discord et compte](discord-account-support.md).

Si un salon manque, un responsable peut mettre à jour les autorisations du bot puis **Actualiser les salons**. Si un envoi est « à vérifier », consulter le salon et vérifier le message existant ; il n’est pas renvoyé automatiquement.

## Import refusé

Vérifier les droits d’import de l’équipe et la présence d’au moins cinq profils joueurs distincts. Contrôler ensuite la version de NXT5 Importer, la région du Game ID et la fin effective de la partie. Réexporter depuis le PC où la game apparaît dans l'historique League of Legends.

## Timeline incomplète

NXT5 masque les événements absents au lieu de les inventer. Un nouveau JSON peut restaurer les informations si l'ancien importeur ne les avait pas incluses. Les statistiques finales restent utilisables si Riot ne fournit pas toute la timeline.

## Profil ou compteur incorrect

Contrôler le compte lié, le Riot ID, les doublons de profil et l'assignation du participant dans chaque game concernée.

## Chargement bloqué

Recharger la page, contrôler la connexion et utiliser Réessayer lorsqu'une erreur API est affichée. Pour un rapport de bug, conserver la page, l'action effectuée et le message visible, sans envoyer de mot de passe ni de fichier privé dans l'assistant.

Si le navigateur manque de fluidité, **Paramètres → Mode visuel → Mode performance** réduit les effets sur cet appareil.
