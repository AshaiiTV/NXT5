# Permissions et dépannage

## Permissions

Les droits dépendent du rôle enregistré dans l'équipe. Les paramètres personnels sont dans `/parametres`; les accès du roster sont dans `/gestion-equipe`. Une action bloquée doit être vérifiée avec le capitaine ou un membre du staff autorisé.

## Compte et connexions

**Paramètres** regroupe le pseudo et l’e-mail, la sécurité, les **Connexions associées**, les e-mails NXT5 et l’affichage sur cet appareil. Un changement d’e-mail envoie un lien à la nouvelle adresse, à ouvrir sous 24 heures dans le navigateur connecté au compte ; l’ancienne adresse reste active jusque-là. Modifier l’e-mail ou dissocier un service demande un mot de passe NXT5, qu’un compte créé avec un service externe peut définir depuis **Sécurité du compte**. **Rester connecté** garde la session 30 jours ; sinon elle se termine à la fermeture du navigateur et au plus tard après 12 heures.

## Commande Discord refusée

Voir [Discord, compte et soutien](discord-compte-soutien.md) : compte lié, salon des commandes de l’équipe, appartenance NXT5 et, s’ils sont configurés, rôles de **Accès aux commandes**.

## Import refusé

Vérifier la version de NXT5 Importer, la région du Game ID et la fin effective de la partie. Réexporter depuis le PC où la game apparaît dans l'historique League of Legends.

## Timeline incomplète

NXT5 masque les événements absents au lieu de les inventer. Un nouveau JSON peut restaurer les informations si l'ancien importeur ne les avait pas incluses. Les statistiques finales restent utilisables si Riot ne fournit pas toute la timeline.

## Profil ou compteur incorrect

Contrôler le compte lié, le Riot ID, les doublons de profil et l'assignation du participant dans chaque game concernée.

## Chargement bloqué

Recharger la page, contrôler la connexion et utiliser Réessayer lorsqu'une erreur API est affichée. Pour un rapport de bug, conserver la page, l'action effectuée et le message visible, sans envoyer de mot de passe ni de fichier privé dans l'assistant.

Si le site manque de fluidité, **Paramètres → Affichage sur cet appareil → Mode performance** réduit les effets visuels dans ce navigateur.
