# Navigation, équipe et profils

## Démarrage

Le parcours recommandé est : créer ou rejoindre une équipe, construire le roster, lier les comptes, importer une game, lire les statistiques ou tendances, puis créer une review.

Le guide de démarrage suit quatre étapes : Roster, Première game, Tendances et Review. Roster ouvre directement [l’ajout de profils](/gestion-equipe?section=roster). L’import demande au moins cinq profils joueurs distincts, remplaçants compris ; le staff ne compte pas. Terminer l’étape Roster demande les cinq postes TOP, JGL, MID, ADC et SUP dans Main Team : ce sont deux critères différents.

Première game ouvre [l’import](/games?import=1) dès que les profils sont prêts. L’étape Tendances propose d’importer jusqu’à trois games, puis d’ouvrir l’analyse. Review ouvre la rédaction sur la dernière game ou une review existante. Les actions indisponibles indiquent le prérequis ou le rôle nécessaire.

Le guide disparaît quand les quatre étapes sont terminées. Sa fermeture est mémorisée par compte et équipe ; tant que le parcours reste incomplet, il peut être repris depuis l’accueil Équipe.

## Équipe

La page [Équipe](/equipes) présente les joueurs, les groupes Main Team et Subs, le staff et les principaux champions joués. Le groupe Main Team sert notamment à ouvrir ou copier l'OP.GG des titulaires sans inclure les remplaçants.

Pour créer ou rejoindre une autre équipe, ouvre le sélecteur d’équipe en haut de l’application, puis **Créer ou rejoindre une équipe**. Sans équipe, les formulaires sont proposés directement. Le sélecteur permet aussi de choisir l’équipe sur laquelle travailler.

## Gestion équipe

La page [Gestion équipe](/gestion-equipe), accessible par le bouton de gestion près du sélecteur d’équipe, permet aux rôles autorisés de :

1. Ajouter ou modifier un profil.
2. Régler son nom, son rôle et son groupe Main Team ou Sub.
3. Lier le bon compte NXT5 au profil.
4. Attribuer un niveau d'accès.
5. Créer une invitation temporaire.

La section Santé des données se consulte aussi dans Gestion équipe. Elle signale les points à vérifier dans le roster, les profils liés et les imports de l’équipe sélectionnée.

Un écart de nombre de games entre deux joueurs peut venir d'une mauvaise assignation de profil dans un import, d'un doublon ou d'un changement de Riot ID. Vérifier les games concernées avant de conclure.

## Mon Profil

[Mon Profil](/mon-profil) regroupe Synthèse, Champions, Pool, Historique et Coaching. Un profil vide doit d'abord être contrôlé dans Gestion équipe, puis dans les assignations des games importées.
