# Vérification locale de l’interface Riot — 23 septembre 2026

Les parcours ont été contrôlés sur un serveur Vite local, avec des réponses API interceptées uniquement par le navigateur de test. Aucun appel d’authentification Riot et aucune requête de production n’ont été exécutés. Ces vérifications ne valident pas un client RSO réel.

## Rendu et accessibilité

Chromium headless, largeurs de 360, 390, 768, 1024 et 1440 px, préférence de mouvement réduit activée :

- Connexion Riot désactivée quand la configuration est indisponible, avec explication lisible.
- Aucun débordement horizontal global sur la connexion et le formulaire de dissociation à ces cinq largeurs ; vérification complémentaire des états non associé, erreur de démarrage et erreur de réauthentification à 390 px.
- Champ de réauthentification à 16 px sur petit mobile, hauteur de 46 px ; boutons de confirmation d’au moins 44 px.
- Focus placé dans le champ à l’ouverture, Échap ferme la confirmation et restitue le focus au déclencheur. Ouverture au clavier avec Entrée vérifiée.
- Une erreur de réauthentification reçoit le focus, garde le compte associé affiché et efface le mot de passe saisi. La dissociation réussie affiche le moyen de connexion NXT5 restant.
- Captures de connexion et de dissociation inspectées sur mobile et ordinateur : palette, retours à la ligne, hiérarchie et styles des composants partagés conservés.
- Le favicon de remplacement a été inspecté visuellement : ses trois branches sont présentes. Aucun usage de l’ancien symbole web incomplet ne reste dans `src/`.
- Aucune erreur JavaScript relevée dans ces parcours.

## Tests automatisés

Le fichier `src/__tests__/riot-account-ui.test.jsx` couvre la disponibilité absente ou malformée, le nouvel essai, les options de session, le rejet des destinations d’autorisation inattendues, l’association explicite, la dissociation avec réauthentification, les erreurs, le clavier et les messages de retour. Le cas d’une identité Riot non associée passe par l’inscription ou la connexion NXT5 ordinaire puis les paramètres, sans déclencher automatiquement d’association.

Exécution ciblée avec `pricing-routing.test.jsx` : 51 tests réussis, dont 22 tests Riot. Les conflits d’identité distinguent un compte Riot déjà associé ailleurs d’un compte NXT5 possédant déjà une autre association. Le lien vers la section de confidentialité et l’annonce de fermeture des autres sessions lors de la dissociation sont également vérifiés. La vérification complète `npm run verify` et les tests serveur sont consignés dans la livraison principale.

Restent nécessaires après approbation Riot : vérifier le client et les URI finalement autorisés, puis réaliser les parcours de consentement, connexion et association réels dans un environnement de validation configuré.
