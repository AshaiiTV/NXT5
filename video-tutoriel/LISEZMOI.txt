Kit voix off ElevenLabs — tuto NXT5
Prérequis : Python 3 + Pillow (pip install pillow), ffmpeg.
1. Définir la clé :  export ELEVENLABS_API_KEY=...   (Windows PowerShell : $env:ELEVENLABS_API_KEY="...")
   Voix utilisée : Léo, voix française native (par défaut dans voice.py, modèle multilingue v2 ; nécessite une offre ElevenLabs payante). Autre voix : ELEVENLABS_VOICE_ID=...
2. Lancer :  sh build.sh   (ou les 3 commandes python qu'il contient)
Résultat : nxt5-tuto-voix.mp4 — la vidéo est recalée sur la durée réelle de chaque phrase.
Texte lu : narration.json (modifiable avant de lancer).

Version courte (≈ 40 s, recommandée) :
  NARRATION=narration_court.json python3 voice.py
  python3 render_court.py tuto_court_muet.mp4
  python3 mix.py tuto_court_muet.mp4 nxt5-tuto-court.mp4
« NXT5 » est écrit « Next Five » dans la narration pour être prononcé « Next five ».
