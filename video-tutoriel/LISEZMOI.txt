Kit voix off ElevenLabs — tuto NXT5
Prérequis : Python 3 + Pillow (pip install pillow), ffmpeg.
1. Définir la clé :  export ELEVENLABS_API_KEY=...   (Windows PowerShell : $env:ELEVENLABS_API_KEY="...")
   Voix par défaut : Brian (narrateur masculin). Pour une autre voix : export ELEVENLABS_VOICE_ID=...
2. Lancer :  sh build.sh   (ou les 3 commandes python qu'il contient)
Résultat : nxt5-tuto-voix.mp4 — la vidéo est recalée sur la durée réelle de chaque phrase.
Texte lu : narration.json (modifiable avant de lancer).
